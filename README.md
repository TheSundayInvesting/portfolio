# Sunday Investing Terminal

Centralized read-only portfolio dashboard hosted on GitHub Pages.

Live version → https://**yourusername**.github.io/

## How to update

1. Go to this repo → **holdings.json** → click pencil (Edit)
2. Modify quantity, average price, add/remove lines
3. Commit changes (green button at bottom)
4. Refresh the dashboard page → data updates within seconds

Prices are updated via GitHub Actions (you can add your own workflow later).

Enjoy your centralized portfolio view!
